윈도우 블루스크린, 한 번이면 괜찮아요. 반복되면 이 순서로

윈도우 11 블루스크린(중지 코드 오류)이 반복될 때 원인을 좁히고 안전 모드로 해결하는 순서예요.

작업하다 갑자기 화면이 바뀌면서 ‘장치에 문제가 발생하여 다시 시작해야 합니다’가 뜨면 PC가 망가진 것 같아 불안해지죠. 그런데 Microsoft는 한 번 재시작하고 멀쩡하다면 대부분 추가 조치가 필요 없다고 안내해요. 문제는 같은 오류가 계속 반복될 때예요. 화면에서 무엇을 적어 둬야 하는지, 부팅조차 안 될 때 어디로 들어가야 하는지 순서대로 정리했어요.

30초 요약
  • 한 번 뜨고 정상으로 돌아왔다면 Microsoft 안내상 보통 추가 조치가 필요 없어요.
  • 반복되면 화면 아래의 중지 코드(예: MEMORY_MANAGEMENT)를 사진으로 남겨 두세요.
  • 최근 단 하드웨어를 빼고, 장치 관리자에서 느낌표(!) 장치의 드라이버를 업데이트해요.
  • 부팅이 안 되면 전원을 두 번 강제로 꺼서 복구 환경에 들어간 뒤 안전 모드로 시작해요.

  2. 화면에서 꼭 남길 것: 중지 코드와 모듈 이름

  5. 저장 공간 10~15% 비우고 최신 업데이트 설치

  7. 업데이트 뒤부터 생겼다면: 업데이트 제거와 시스템 복원
  8. 주의와 마무리: 재시작 루프, 안전 모드 탈출, 서비스센터

결론부터: 한 번은 괜찮고, 반복이 문제예요

Microsoft는 이 화면을 중지 코드 오류라고 불러요. 버그 검사, 커널 오류, 블루스크린, 블랙 스크린 오류, BSOD도 모두 같은 현상이에요. 심각한 문제가 생기면 윈도우가 데이터를 지키려고 스스로 멈춘 뒤 자동으로 다시 시작해요.

원인은 하드웨어, 드라이버, 소프트웨어 중 하나인 경우가 많아요. Microsoft 안내로는 대부분의 경우 재시작하면 문제가 풀리고 추가 조치가 필요 없어요.

결론한 번 뜨고 정상으로 돌아왔다면 지켜보기만 해도 돼요. 같은 중지 코드로 자주 다시 시작될 때부터 아래 순서를 따라가세요.

화면에서 꼭 남길 것: 중지 코드와 모듈 이름

원인을 좁히는 가장 중요한 단서는 화면 아래쪽 글자예요. PAGE_FAULT_IN_NONPAGED_AREA나 MEMORY_MANAGEMENT 같은 중지 코드가 나오고, 알 수 있는 경우에는 문제가 생길 때 실행 중이던 모듈 이름도 함께 표시돼요.

  1. 다음에 화면이 뜨면 휴대폰으로 바로 사진을 찍어 둬요.
  2. 중지 코드와 모듈 이름(예: 파일 이름 끝이 .sys인 것)을 메모해요.
  3. 언제 떴는지(게임 중, 절전 해제 직후, 특정 장치 연결 후)도 같이 적어요.
참고윈도우 11 24H2 이후 버전은 화면 색과 문구가 예전 버전과 다르게 보일 수 있어요. 파란색이 아니라 검은 화면이어도 같은 오류예요.

최근에 바꾼 것부터 되돌리기

오류가 시작되기 직전에 새로 단 하드웨어가 있다면 그게 첫 번째 용의자예요. Microsoft도 기본 문제 해결의 첫 단계로 새 하드웨어 제거를 안내해요.

  1. PC를 끄고 최근에 추가한 하드웨어를 빼요. 새 메모리, 그래픽카드, SSD, USB 허브, 도킹 스테이션 같은 것들이에요.
  2. 꼭 필요한 키보드와 마우스만 연결한 상태로 다시 켜요.
  3. 며칠 써 보면서 같은 중지 코드가 또 뜨는지 봐요.
  4. 안 뜬다면 뺀 장치를 하나씩 다시 연결해서 어느 장치에서 오류가 나는지 찾아요.
팁한 번에 여러 개를 바꾸면 원인을 알 수 없어요. 꼭 하나씩 다시 연결하세요.

장치 관리자에서 느낌표(!) 장치 처리하기

드라이버 문제는 장치 관리자에서 바로 보이는 경우가 많아요.

  1. 시작 버튼을 마우스 오른쪽 버튼으로 클릭하고 장치 관리자를 선택해요.
  2. 목록을 펼쳐서 느낌표(!)가 표시된 장치가 있는지 찾아요.
  3. 그 장치를 마우스 오른쪽 버튼으로 클릭하고 ‘드라이버 업데이트’를 선택해요.
  4. 업데이트해도 그대로라면 같은 메뉴에서 장치를 사용 안 함으로 바꾸거나 제거해 봐요.
주의출처를 알 수 없는 사이트의 ‘드라이버 자동 설치 프로그램’은 쓰지 마세요. 그래픽카드나 메인보드 드라이버가 필요하면 제조사 공식 사이트에서 받는 게 안전해요.

저장 공간 10~15% 비우고 최신 업데이트 설치

의외로 저장 공간 부족도 원인이 돼요. 윈도우와 일부 앱은 작업 중에 임시로 쓰는 파일을 만들 공간이 필요하기 때문이에요. Microsoft는 전체 공간의 10%에서 15% 정도를 비워 두라고 권장해요.

  1. 파일 탐색기에서 C 드라이브의 남은 공간을 확인해요.
  2. 여유 공간이 10% 아래라면 큰 동영상, 안 쓰는 앱, 다운로드 폴더부터 정리해요.
  3. 시작 > 설정 > Windows 업데이트에서 ‘업데이트 확인’을 눌러 최신 업데이트를 설치해요.
  4. 설치 후 다시 시작하고 같은 오류가 반복되는지 지켜봐요.
참고윈도우 업데이트에는 알려진 오류를 고치는 수정이 함께 들어오는 경우가 많아요.

부팅이 안 될 때: 복구 환경으로 들어가 안전 모드로

블루스크린이 계속 떠서 윈도우에 들어가지도 못한다면 윈도우 복구 환경(Windows RE)을 써요. 안전 모드는 꼭 필요한 파일과 드라이버만으로 윈도우를 켜는 모드라, 안전 모드에서 괜찮다면 기본 드라이버와 설정은 원인이 아니라는 뜻이에요.

  1. PC를 켜고 윈도우 로고가 나오면 전원 버튼을 길게 눌러 강제로 꺼요.
  2. 같은 동작을 한 번 더 해요.
  3. 세 번째로 켜면 자동 복구 화면이 나와요. 여기서 ‘고급 옵션’을 선택해요.
  4. 문제 해결 > 고급 옵션 > 시작 설정 > 다시 시작으로 들어가요.
  5. 다시 시작되면 4 또는 F4를 눌러 안전 모드로, 인터넷이 필요하면 5 또는 F5를 눌러요.
주의암호화된 PC라면 이 과정에서 BitLocker 복구 키를 물어볼 수 있어요. 미리 키 위치를 확인해 두세요.

업데이트 뒤부터 생겼다면: 업데이트 제거와 시스템 복원

특정 업데이트를 설치한 뒤부터 오류가 시작됐다면 복구 환경의 도구로 되돌릴 수 있어요. 복구 환경의 고급 옵션에는 이런 도구가 있어요.

  1. 업데이트 제거: 최근에 설치한 윈도우 업데이트를 지워요.
  2. 시스템 복원: 시스템 파일과 설정을 예전 복원 지점으로 되돌려요. 개인 파일은 건드리지 않아요.
  3. 시동 복구: 윈도우가 시작되지 못하게 하는 흔한 문제를 자동으로 진단하고 고쳐요.
  4. 이 PC 초기화: 공장 상태로 되돌려요. 개인 파일을 유지할지 지울지 고를 수 있어요.
팁위에서부터 차례로 해 보고, 초기화는 마지막에 쓰세요. 초기화 전에는 중요한 파일을 꼭 다른 곳에 백업하세요.

주의와 마무리: 재시작 루프, 안전 모드 탈출, 서비스센터

재시작이 끝없이 반복돼서 화면을 읽을 틈도 없다면 시작 설정 화면에서 9 또는 F9 ‘시스템 오류 시 자동 다시 시작 사용 안 함’을 고르면 돼요. 그러면 오류 화면이 바로 넘어가지 않아서 중지 코드를 확인할 수 있어요. Microsoft는 재시작 루프에 갇혔을 때만 이 옵션을 쓰라고 안내해요.

안전 모드에서 빠져나오지 못한다면 이렇게 해요.

  1. Windows 키 + R을 누르고 msconfig를 입력해요.
  2. 부팅 탭에서 ‘안전 부팅’ 체크를 해제하고 다시 시작해요.
결론위 단계를 다 해도 같은 중지 코드가 반복된다면 메모리나 저장장치 같은 하드웨어 문제일 수 있어요. 적어 둔 중지 코드와 사진을 들고 PC 제조사 서비스센터에 점검을 받으세요.

자주 묻는 질문

블루스크린이 한 번 떴는데 괜찮은 건가요?

Microsoft는 대부분의 경우 다시 시작하면 문제가 해결되고 추가 조치가 필요 없다고 안내해요. 같은 중지 코드로 자주 다시 시작될 때만 하드웨어 제거, 드라이버 업데이트 같은 문제 해결을 진행하면 돼요.

중지 코드 화면이 너무 빨리 지나가서 못 읽었어요.

재시작 루프에 갇힌 상태라면 복구 환경의 시작 설정에서 9 또는 F9 ‘시스템 오류 시 자동 다시 시작 사용 안 함’을 고르세요. 화면이 바로 넘어가지 않아서 중지 코드를 사진으로 남길 수 있어요.

안전 모드로 들어갔는데 계속 안전 모드로만 켜져요.

Windows 키 + R을 눌러 msconfig를 실행하고, 부팅 탭에서 ‘안전 부팅’ 체크를 해제한 뒤 다시 시작하세요. Microsoft가 안내하는 방법이에요.

복구 환경에 들어가니 BitLocker 복구 키를 물어봐요.

장치가 암호화돼 있으면 일부 복구 도구를 쓸 때 BitLocker 복구 키가 필요해요. 다른 기기에서 aka.ms/myrecoverykey에 Microsoft 계정으로 로그인하면 저장된 키를 확인할 수 있어요.
