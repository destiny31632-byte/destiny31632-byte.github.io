윈도우 11 블루투스 연결됐는데 무음? 출력 장치부터 확인해요

윈도우 11에서 블루투스 이어폰이 연결됐지만 소리가 없을 때 출력·앱 음량·드라이버를 확인해요.

이어폰에는 '연결됨'이라고 뜨는데 영상 소리는 노트북 스피커로만 나올 수 있어요. 블루투스 연결이 성공해도 Windows가 그 장치를 출력 대상으로 고르지 않았을 수 있거든요. 페어링 정보를 지우기 전에 출력 장치와 앱별 음량부터 확인하면 문제 범위를 쉽게 좁힐 수 있어요.

30초 요약
  • 설정 > 시스템 > 사운드에서 블루투스 이어폰이 출력 장치로 선택됐는지 확인해요.
  • 특정 앱에서만 무음이면 볼륨 믹서의 앱 음소거와 출력 장치를 먼저 봐요.
  • 전부 무음이면 블루투스를 껐다 켜고 필요할 때 장치를 다시 연결해요.
  • 계속 안 되면 도움말의 블루투스 문제 해결사와 제조사 드라이버를 점검해요.

연결됨 표시와 소리 출력은 서로 달라요

블루투스 목록에 이어폰이 연결됐다고 표시돼도 그 장치로 소리를 내보내도록 설정됐다는 뜻은 아니에요. Windows는 노트북 스피커, 모니터, USB 헤드셋, 블루투스 이어폰을 별도의 출력 대상으로 관리해요. 이어폰으로 음악을 재생하면서 노트북 스피커에서는 들리는지, 아예 아무 장치에서도 소리가 안 나는지 먼저 구분해 보세요. Microsoft도 블루투스 연결 후 무음 문제에서 출력 장치를 확인하도록 안내해요. 여러 오디오 장치를 연결해 두었다면 사용하지 않는 장치를 잠시 분리해 비교해도 좋아요. 여기서 문제가 해결되면 이어폰을 초기화하거나 드라이버를 다시 설치할 필요는 없어요.

Windows 출력 장치를 이어폰으로 바꿔요

작업 표시줄의 소리 아이콘 옆 출력 선택 화면에서 다른 스피커가 선택돼 있는지 살펴보세요. Windows 11에서는 설정 > 시스템 > 사운드의 출력 항목에서도 연결된 장치를 고를 수 있어요. 이어폰을 고른 뒤 시스템 소리와 동영상 소리를 각각 들어보면 전환 여부를 확인하기 쉬워요. 이어폰 자체의 음량이 낮을 수도 있으니 Windows 음량과 이어폰 터치 조절도 함께 살펴보세요. 출력 목록에 이어폰이 없으면 단순한 음소거 문제보다 연결 상태나 드라이버가 원인일 수 있어요. 설정을 바꾼 뒤에는 같은 동영상을 다시 틀어 비교해요.

  1. 시작 > 설정 > 시스템 > 사운드를 열어요.
  2. 출력 목록에서 연결된 블루투스 이어폰을 선택해요.
  3. 음소거를 해제하고 적당한 음량에서 짧은 소리를 재생해요.

특정 앱만 무음이라면 볼륨 믹서를 확인해요

웹브라우저는 소리가 나는데 게임이나 회의 앱만 조용하다면 이어폰 고장으로 단정하지 마세요. Windows는 앱마다 음량과 출력 장치를 다르게 기억할 수 있어요. Microsoft의 앱 오디오 문제 안내에도 볼륨 믹서에서 개별 앱의 음소거와 출력 설정을 확인하라고 나와 있어요. 테스트하려는 앱에서 실제로 소리를 재생한 상태로 확인하면 해당 항목을 찾기가 쉬워요. 회의 앱 안에도 스피커 선택 메뉴가 있을 수 있으니 Windows 설정이 맞는데 회의 소리만 안 나오면 앱 설정도 비교해요.

  1. 설정 > 시스템 > 사운드에서 볼륨 믹서를 열어요.
  2. 문제가 생긴 앱이 음소거 상태인지 확인해요.
  3. 해당 앱의 출력 장치가 이어폰인지 확인하고 다시 재생해요.

소리가 끊기거나 음질이 낮으면 형식도 점검해요

연결은 유지되는데 소리가 뭉개지거나 간헐적으로 끊긴다면 Microsoft가 안내하는 오디오 형식 점검을 시도할 수 있어요. 연결된 블루투스 장치의 고급 사운드 속성에서 지원하는 형식이 보이는 경우 2채널, 16비트, 48000Hz를 선택하는 절차가 공식 도움말에 나와 있어요. 다만 모든 이어폰과 Windows 버전에서 같은 항목이 나타나지는 않아요. 목록에 없는 값을 억지로 추가하거나 레지스트리를 바꾸지는 마세요. 소리 출력 장치와 앱별 음량을 확인한 다음 형식을 조정해야 어느 변경으로 증상이 달라졌는지 구분할 수 있어요. 변경 뒤 음질이 더 나빠졌다면 이전 값으로 되돌려 비교해요.

이어폰 연결이 꼬였다면 다시 페어링해요

출력 장치를 제대로 골랐는데도 연결이 불안정하면 먼저 블루투스를 껐다 켜 보세요. 잠시 껐다 다시 켜는 과정에서 일시적인 연결 문제가 풀리는지 확인할 수 있어요. 같은 이어폰이 휴대전화에도 연결돼 있다면 제품 설명서에서 두 기기 동시 연결을 지원하는지 확인하는 편이 좋아요. 그래도 이어폰이 출력 목록에 나타나지 않거나 선택되지 않을 때는 기존 페어링을 제거하고 새로 추가해요. 장치를 제거하면 이전 연결 정보가 사라지므로 이어폰을 다시 페어링할 준비를 해두세요.

  1. 설정 > Bluetooth 및 장치에서 블루투스를 껐다 켜요.
  2. 그대로라면 목록에서 이어폰을 제거해요.
  3. 이어폰을 제조사가 안내한 페어링 모드로 만든 뒤 디바이스 추가로 연결해요.

연결 자체가 실패하면 문제 해결사와 드라이버를 봐요

출력 목록에 이어폰이 안 보이거나 연결 자체가 계속 실패한다면 Windows 11의 도움말 앱에 있는 자동 블루투스 문제 해결사를 실행해 보세요. Microsoft는 드라이버가 오래됐거나 Windows 업데이트 뒤 호환되지 않는 상황도 가능한 원인으로 안내해요. 장치 관리자에서 블루투스 어댑터를 찾아 드라이버 업데이트를 확인하고, 컴퓨터 제조사가 제공하는 모델별 드라이버도 살펴보세요. 업데이트 뒤 재시작 안내가 나오면 재시작한 다음 확인해요. 블루투스 오디오 재생에 필요한 A2DP 지원 여부는 이어폰의 제품 설명서에서 확인할 수 있어요. 출처가 불분명한 드라이버 설치 프로그램은 이용하지 않는 편이 안전해요.

Windows 초기화 전에 장치별로 원인을 나눠요

이어폰을 다른 휴대전화에 연결해도 소리가 안 나는지, 문제의 Windows 노트북에서는 다른 블루투스 스피커가 정상인지 비교해 보세요. 이어폰 한 제품에서만 무음이면 이어폰의 설정과 배터리, 펌웨어를 확인하고 여러 이어폰이 모두 무음이면 컴퓨터의 출력 설정과 블루투스 어댑터를 먼저 살펴봐요. Windows 업데이트 직후 발생했다면 업데이트 날짜와 드라이버 버전도 메모해 두세요. 중요한 회의가 있다면 이미 정상 작동하는 유선 헤드셋을 임시로 쓰면서 진단해도 돼요. 원인을 찾기 전 Windows 전체 초기화부터 진행하면 불필요한 데이터 정리와 재설정이 생길 수 있어요.

지원 문의에는 재현 조건을 전달해요

앞 단계에서도 무음이면 연결 상태가 '연결됨'인지, 출력 목록에 이어폰이 보이는지, 전부 무음인지 특정 앱만 무음인지 정리해요. Windows 버전, 노트북과 이어폰 모델, 최근 업데이트 날짜, 문제 해결사를 실행한 결과도 기록하세요. 문의받는 쪽에서 같은 단계를 반복하지 않고 다음 원인을 확인하는 데 도움이 돼요. 회사 노트북처럼 드라이버 설치 권한이 제한돼 있다면 임의로 보안 설정을 바꾸지 말고 관리자에게 현상을 전달해요. Microsoft 도움말과 제조사 지원을 함께 확인하되, 회의 계정 비밀번호나 개인 인증 정보가 진단용 화면에 보이지 않도록 주의하세요.

자주 묻는 질문

윈도우 11 블루투스 이어폰 연결됐는데 소리가 안 나요. 고장인가요?

장치가 연결됐더라도 Windows가 노트북 스피커를 출력으로 선택했을 수 있어요. 설정 > 시스템 > 사운드에서 블루투스 이어폰을 출력으로 지정하고 음량을 확인한 뒤 고장 여부를 판단해 보세요.

유튜브는 들리는데 게임이나 회의 앱만 블루투스 소리가 안 나요?

특정 앱에서만 발생하면 설정 > 시스템 > 사운드 > 볼륨 믹서를 먼저 보세요. 개별 앱 음소거와 출력 장치가 다르게 설정됐을 수 있고, 회의 앱처럼 앱 내부에서 스피커를 따로 선택하는 경우도 있어요.

블루투스 이어폰을 다시 추가해도 무음이면 어떡하나요?

Windows 도움말의 블루투스 문제 해결사를 실행하고 컴퓨터 제조사가 제공하는 블루투스 드라이버를 확인해 보세요. 다른 이어폰에서도 같은 증상이 나타나는지 비교하면 이어폰과 컴퓨터 중 어느 쪽을 점검할지 좁힐 수 있어요.
