윈도우 업데이트 후 USB 오디오 무음·코드 10, 아직 완전 해결은 아니다

9월 Windows 업데이트 뒤 USB 오디오가 무음이거나 코드 10이 뜰 때 공식 완화 범위와 점검 순서.

1. 9월 업데이트 뒤 USB 오디오만 죽었다면 장치부터 버리지 않는다

2026년 9월 8일 Windows 보안 업데이트 뒤 USB DAC, 오디오 인터페이스, 스피커처럼 USB로 연결한 오디오 장치만 갑자기 무음이 됐다면 먼저 Windows의 알려진 문제인지 확인한다. Microsoft는 일부 USB Audio Class 1.0 장치에서 시작 실패, 무음, 볼륨 0 고정, 소리 설정 응답 불가가 생길 수 있다고 공식 안내하고 있다. 장치 관리자에서 ‘이 장치를 시작할 수 없습니다(코드 10)’가 함께 보일 수도 있다. 증상이 업데이트 직후 시작됐고 내장 스피커나 다른 출력은 정상이라면 새 케이블이나 새 DAC를 바로 사기보다 설치된 KB와 장치 유형을 먼저 확인한다.

2. 같은 무음이라도 이 문제에 해당하는지 먼저 가른다

이 이슈는 Microsoft 설명상 USB Audio Class 1.0 장치에 제한된다. 블루투스 이어폰, HDMI 모니터 오디오, 메인보드 내장 오디오까지 모두 동시에 안 된다면 다른 원인을 함께 봐야 한다. 확인 순서는 1) 설정 > 시스템 > 소리에서 출력 장치 목록 확인, 2) 장치 관리자에서 해당 USB 오디오 장치의 상태와 코드 10 여부 확인, 3) 업데이트 기록에서 9월 8일 전후 보안 업데이트 설치 시점 확인이다. 멀티채널에서만 안 되고 2채널 스테레오에서는 소리가 나는 경우도 공식 증상에 포함된다. 장치가 아예 USB 장치로 인식되지 않는다면 포트나 케이블 문제도 따로 확인한다.

3. 최신 Windows 업데이트를 먼저 설치하되 완치로 단정하지 않는다

Microsoft는 2026년 9월 14일 대역 외 업데이트 KB5129195와 그 이후 업데이트로 이 문제를 ‘부분적으로’ 해결했다고 밝히고 있다. 따라서 설정 > Windows 업데이트에서 최신 업데이트를 설치하고 재부팅하는 것이 첫 해결 단계다. 다만 공식 문서상 해결된 범위는 8채널 또는 3D 오디오 모드에서 실패하던 증상이며, 코드 10이나 일반 무음 등 다른 증상은 추가 수정이 진행 중이다. 최신 업데이트를 설치한 뒤에도 USB Audio Class 1.0 장치가 시작되지 않는다면 ‘패치했으니 하드웨어 고장’이라고 결론 내리지 않는다. 현재 상태가 완전 해결이 아닌 완화 단계라는 점을 기준으로 다음 점검을 이어간다.

4. 멀티채널만 안 되면 2채널 전환을 임시 확인용으로 쓴다

표준 스테레오에서는 정상인데 8채널이나 3D 오디오를 켰을 때만 소리가 끊긴다면 출력 형식을 2채널로 바꿔 증상이 달라지는지 확인할 수 있다. Microsoft도 일부 사용자가 2채널 모드로 전환해 오디오를 복원했다고 기록했고, 이 멀티채널 증상은 9월 14일 대역 외 업데이트에서 해결됐다고 설명한다. 따라서 2채널 전환은 원인 범위를 좁히는 임시 방법으로는 쓸 수 있지만, 모든 USB 오디오 무음 문제의 공통 해결책은 아니다. 녹음이나 다채널 작업이 필요한 장비라면 채널 수를 낮춘 상태를 최종 해결로 여기지 말고 최신 업데이트 적용 후 원래 설정으로 다시 시험한다.

5. 24H2·25H2뿐 아니라 다른 Windows 버전도 영향 범위를 확인한다

Microsoft의 25H2 릴리스 상태 문서는 이 문제의 영향을 받는 클라이언트로 Windows 11 26H2, 26H1, 25H2, 24H2, 23H2와 일부 Windows 10 버전을 함께 적고 있다. 같은 증상이라도 설치된 업데이트 번호는 버전에 따라 달라질 수 있으므로 다른 사람의 KB 번호만 그대로 따라 하면 혼란이 생긴다. winver 또는 설정 > 시스템 > 정보에서 현재 버전과 OS 빌드를 확인한 뒤 해당 버전의 업데이트 기록을 본다. Windows 11 24H2·25H2에서는 9월 8일 KB5124008이 기준이지만, 다른 버전은 다른 9월 보안 업데이트 번호를 사용할 수 있다. 해결 절차는 자신의 버전에 맞는 최신 누적 업데이트를 받는 것이 우선이다.

6. 드라이버 삭제와 레지스트리 수정은 처음부터 하지 않는다

코드 10을 보면 인터넷에서 찾은 드라이버를 강제로 설치하거나 장치 관리자에서 드라이버 패키지를 지우고 싶을 수 있다. 하지만 업데이트와 시점이 정확히 맞고 Microsoft가 동일 증상을 알려진 문제로 추적 중이라면 먼저 OS 수정 상태를 확인하는 편이 안전하다. 제조사 전용 드라이버가 있는 오디오 인터페이스라면 제조사 지원 페이지에서 현재 Windows 버전용 드라이버가 따로 있는지 확인한 뒤 설치한다. 출처를 알 수 없는 드라이버, 오래된 드라이버 패키지, 레지스트리 청소 프로그램은 피한다. 복구 지점이나 현재 드라이버 버전을 기록하지 않은 채 여러 항목을 한꺼번에 바꾸면 무엇이 문제를 바꿨는지 확인하기도 어렵다.

7. 업데이트 뒤에도 안 되면 다른 출력과 다른 PC로 고장 범위를 좁힌다

최신 Windows 업데이트와 재부팅 뒤에도 문제가 남으면 하드웨어와 OS를 교차 확인한다. 1) 같은 PC의 내장 스피커나 HDMI 오디오가 정상인지 확인, 2) 문제가 있는 USB 오디오 장치를 다른 USB 포트에 직접 연결, 3) 허브를 쓰고 있었다면 허브를 제거, 4) 가능하면 다른 PC에서 같은 장치가 정상 작동하는지 확인한다. 다른 PC에서는 정상인데 9월 업데이트가 설치된 PC에서만 코드 10이 반복되면 Windows 쪽 가능성이 더 커진다. 반대로 여러 PC에서 모두 인식이 끊기거나 전원조차 들어오지 않으면 케이블, 전원, 장치 고장을 별도로 점검해야 한다. 한 번에 한 요소만 바꿔야 판단이 쉽다.

8. 작업용 장비라면 백업 경로를 만들고 공식 수정 상태를 계속 확인한다

녹음, 화상회의, 수업처럼 USB 오디오가 꼭 필요한 PC라면 임시 우회가 가능한 출력 장치를 준비해 두는 편이 낫다. Microsoft 문서가 현재 문제를 ‘완화’ 상태로 두고 있어 코드 10과 일반 무음 증상은 추가 업데이트로 바뀔 수 있다. 설정 > Windows 업데이트에서 최신 누적 업데이트를 확인하고, Microsoft의 Windows 11 알려진 문제 페이지에서 USB 오디오 항목의 상태와 마지막 업데이트 날짜도 함께 본다. 문제가 계속되면 장치 모델명, USB Audio Class 여부, Windows 버전과 빌드, 설치된 KB 번호, 장치 관리자 오류 코드를 기록해 제조사와 Microsoft 지원에 전달한다. 중요한 작업 직전에 드라이버를 대량 삭제하거나 Windows 초기화를 먼저 하는 것은 피한다.
