윈도우 업데이트 실패? 0x800f0922 등 오류 코드별 MS 공식 해결 순서

윈도우 11 업데이트가 실패하거나 멈출 때 오류 코드별 원인과 Microsoft가 안내하는 해결 순서예요.

윈도우 업데이트가 몇 번을 다시 해도 ‘업데이트를 설치하지 못했습니다’와 함께 0x로 시작하는 코드만 남긴다면 답답하죠. Microsoft는 이 오류 코드마다 원인과 해결법을 따로 정리해 두고 있어요. 공간이 부족해서 실패하는 0x800f0922처럼, 코드만 보면 어디부터 손대야 할지 바로 알 수 있는 경우가 많아요. 기본 순서와 코드별 해결법을 한 번에 정리했어요.

30초 요약
  • 먼저 시작 > 설정 > 시스템 > 문제 해결 > 기타 문제 해결사에서 Windows 업데이트 문제 해결사를 실행하세요.
  • 0x800f0922는 공간 부족이 흔한 원인이에요. 64비트는 20GB 이상 여유 공간이 필요해요.
  • 업데이트 캐시가 손상되면 SoftwareDistribution 폴더를 비우고 다시 시도해요.
  • 어떤 방법이든 시도하기 전에 중요한 파일부터 백업하세요. Microsoft도 가장 먼저 안내하는 단계예요.

결론부터: 백업하고, 문제 해결사부터 돌리세요

Microsoft는 윈도우 업데이트 문제를 고치기 전에 개인 파일부터 백업하라고 안내해요. USB 드라이브에 중요한 파일을 복사하거나 OneDrive로 백업하면 돼요. Microsoft 계정으로 로그인했다면 업데이트 후 시스템 설정은 인터넷 연결 시 자동으로 복원돼요.

그다음 첫 단계는 자동 문제 해결사예요.

  1. 시작 > 설정 > 시스템으로 들어가요.
  2. ‘문제 해결’을 고르고 ‘기타 문제 해결사’를 선택해요.
  3. Windows 업데이트 옆의 ‘실행’을 눌러요.
  4. 화면 안내를 따라 끝까지 진행해요.
결론문제 해결사가 자동으로 진단하고 대부분의 문제를 고치려고 시도해요. 그래도 안 되면 아래 기본 점검과 오류 코드별 해결로 넘어가요.

기본 점검: 인터넷, 관리자 권한, 외장 장치, 날짜

Microsoft가 안내하는 일반 문제 해결 단계 중 간단한 것부터 해요.

  1. 전원에 연결돼 있고 인터넷이 안정적인지 확인해요. 시작 > 설정 > 네트워크 및 인터넷 > Wi-Fi에서 연결 상태를 봐요.
  2. 관리자 계정으로 로그인했는지 확인해요. 일부 업데이트는 관리자 권한이 필요해요.
  3. 외장 저장장치, 도크처럼 꼭 필요하지 않은 외장 하드웨어를 모두 빼고 다시 시도해요.
  4. 시작 > 설정 > 시간 및 언어 > 날짜 및 시간에서 ‘자동으로 시간 설정’과 ‘자동으로 표준 시간대 설정’을 켜고, 필요하면 ‘지금 동기화’를 눌러요.
참고날짜와 시간이 틀어져 있으면 업데이트가 방해받을 수 있어요. 의외로 이것만으로 풀리는 경우가 있어요.

공간 확보: 20GB가 기준이에요

공간 부족은 업데이트 실패의 대표 원인이에요. Microsoft 기준으로 32비트 윈도우를 업그레이드하려면 16GB 이상, 64비트는 20GB 이상의 여유 공간이 필요해요.

  1. 파일 탐색기에서 C 드라이브의 남은 공간을 확인해요.
  2. 20GB보다 적다면 큰 동영상, 안 쓰는 앱, 다운로드 폴더를 정리해요.
  3. 저장장치 용량 자체가 작은 PC라면 USB 드라이브를 꽂아 업데이트에 쓰게 해요.
  4. 공간을 확보한 뒤 시작 > 설정 > Windows 업데이트에서 다시 ‘업데이트 확인’을 눌러요.
팁업데이트 하나를 받은 뒤에도 추가 업데이트가 이어서 나올 수 있어요. 더 이상 새 업데이트가 없을 때까지 다시 확인하고, 설치 뒤에는 꼭 다시 시작하세요.

업데이트 캐시 지우기: SoftwareDistribution

업데이트 파일을 내려받아 두는 캐시가 손상되면 오류가 날 수 있어요. Microsoft가 안내하는 캐시 지우는 방법이에요.

  1. Win + R을 누르고 services.msc를 입력한 뒤 Enter를 눌러요.
  2. 목록에서 ‘Windows Update’ 서비스를 찾아 마우스 오른쪽 버튼으로 누르고 ‘중지’를 골라요.
  3. 파일 탐색기에서 C:\Windows\SoftwareDistribution 폴더로 이동해요.
  4. 이 폴더 안의 파일과 폴더를 모두 지워요.
  5. 서비스 창으로 돌아가 Windows Update를 다시 마우스 오른쪽 버튼으로 누르고 ‘시작’을 골라요.
  6. Windows 업데이트를 다시 실행해요.
주의SoftwareDistribution 폴더 자체가 아니라 그 안의 내용만 지우는 거예요. 서비스를 멈추지 않고 지우면 일부 파일이 지워지지 않을 수 있어요.

오류 코드별 원인과 해결 ①

Microsoft가 정리한 주요 오류 코드와 해결법이에요.

  • 0x8007000d: 업데이트 파일 문제나 캐시 손상이에요. 문제 해결사를 돌리고 업데이트 캐시를 지워요.
  • 0x800705b4: 설치가 너무 오래 걸리거나 중단된 경우예요. 인터넷 연결을 확인하고, 업데이트를 막을 수 있는 백신이나 방화벽을 잠시 꺼 본 뒤 PC를 다시 시작해요.
  • 0x80240034: 불완전한 업데이트나 연결 문제로 중단된 경우예요. Windows Update 서비스가 실행 중인지 services.msc에서 확인하고 문제 해결사를 돌려요.
  • 0x800f0922: 디스크 공간 부족이나 .NET Framework 같은 구성 요소 문제예요. 공간을 확보하고, VPN을 쓰고 있다면 끄고 다시 시도해요.
주의백신이나 방화벽을 끄는 건 업데이트하는 동안만이에요. 끝나면 바로 다시 켜세요.

오류 코드별 원인과 해결 ②

나머지 코드들이에요.

  • 0x80070057, 0x80080005: 손상된 파일이나 잘못된 시스템 구성이에요. 관리자 권한 명령 프롬프트에서 sfc /scannow를 실행하고 문제 해결사를 돌려요.
  • 0xC1900101: 호환되지 않는 드라이버 때문이에요. 장치 관리자에서 네트워크 어댑터나 디스플레이 어댑터 드라이버를 업데이트하거나 제거한 뒤 다시 시작해요. 필요하면 클린 부팅으로 충돌을 줄여요.
  • 0x80248014: 업데이트 데이터베이스 문제나 서비스가 멈춘 경우예요. 문제 해결사를 돌리고 Windows Update 서비스를 시작해요.
  • 0x80070005: 접근 거부, 권한 부족이에요. 관리자 계정인지 확인하고 백신이나 방화벽을 잠시 꺼 봐요.
  • 0x80070002: 설치 실패예요. PC를 다시 시작하고, 문제 해결사를 돌리고, 공간을 확인해요.
팁하드웨어를 추가한 PC라면 하드웨어 제조사 사이트에서 최신 드라이버를 먼저 설치하세요.

0%·100%에서 멈추거나 51~99%에서 안 끝날 때

업데이트가 특정 숫자에서 멈춰 있을 때도 Microsoft 안내가 있어요.

0%나 100%에서 멈췄다면 이렇게 해요.

  1. PC를 다시 시작해서 다른 프로그램이 업데이트를 막고 있지 않은지 확인해요.
  2. 시작 > 설정 > 네트워크 및 인터넷 > Wi-Fi에서 연결 상태를 확인해요.
  3. 여유 공간이 64비트 기준 20GB 이상인지 확인해요.

51~99%에서 안 끝난다면 연결 속도, 네트워크 설정, 업데이트 크기에 따라 시간이 오래 걸릴 수 있어요. 같은 숫자에서 계속 멈춰 있으면 시작 > 설정 > Windows 업데이트에서 다시 확인하거나 문제 해결사를 실행해요.

참고설치를 적용하려면 대부분 다시 시작해야 해요. 작업을 저장하고 전원 > 업데이트 및 다시 시작을 고르세요.

그래도 안 되면: 고급 복구 명령과 새로 설치

Microsoft는 아래 단계는 명령줄 작업이 익숙한 사용자만, 관리자 권한으로 하라고 안내해요.

  1. 관리자 권한 명령 프롬프트에서 한 줄씩 입력해요: net stop bits, net stop wuauserv, ren %systemroot%\softwaredistribution softwaredistribution.bak, ren %systemroot%\system32\catroot2 catroot2.bak, net start bits, net start wuauserv. 끝나면 PC를 다시 시작해요.
  2. DISM.exe /Online /Cleanup-image /Restorehealth 를 실행하고, 성공 메시지가 나오면 sfc /scannow 를 실행해요.
  3. chkdsk /f C: 로 디스크 오류를 복구해요.
  4. 타사 백신이 원인일 수 있으니 재설치 방법과 제품 키를 확인한 뒤 잠시 제거하고 업데이트해요.
주의마지막 수단은 Microsoft 소프트웨어 다운로드 페이지의 도구로 윈도우 11을 새로 설치하는 거예요. 반드시 백업한 뒤, 페이지의 주의 사항을 읽고 진행하세요.

자주 묻는 질문

윈도우 업데이트 오류 0x800f0922는 왜 생기나요?

Microsoft는 디스크 공간 부족이나 .NET Framework 같은 구성 요소 문제를 원인으로 안내해요. 64비트 윈도우 기준 20GB 이상 여유 공간을 확보하고, VPN을 쓰고 있다면 끈 뒤 다시 시도하세요.

업데이트 캐시는 어떻게 지우나요?

services.msc에서 Windows Update 서비스를 중지하고, C:\Windows\SoftwareDistribution 폴더 안의 내용을 모두 지운 뒤 서비스를 다시 시작하면 돼요. 그다음 Windows 업데이트를 다시 실행하세요.

업데이트가 100%에서 몇 시간째 멈춰 있어요.

Microsoft는 PC를 다시 시작해 다른 프로그램이 업데이트를 막고 있지 않은지 확인하고, 인터넷 연결과 여유 공간을 점검하라고 안내해요. 그래도 같으면 업데이트를 다시 확인하거나 문제 해결사를 실행하세요.

업데이트 전에 꼭 백업해야 하나요?

Microsoft는 문제 해결 방법을 시도하기 전에 개인 파일을 백업하라고 가장 먼저 안내해요. 특히 명령줄 복구나 새로 설치까지 갈 수 있으니, USB나 OneDrive에 중요한 파일을 미리 복사해 두세요.
