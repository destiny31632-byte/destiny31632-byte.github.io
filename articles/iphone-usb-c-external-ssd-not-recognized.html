아이폰에서 USB-C 외장 SSD가 안 보일 때 확인할 것

아이폰 파일 앱에 USB-C 외장 SSD가 안 보일 때 잠금 상태, 포맷, 파티션, 전원과 케이블을 순서대로 확인하는 방법.

1. 아이폰 잠금을 풀고 파일 앱 위치 목록을 확인한다

SSD를 연결한 뒤 아이폰 잠금을 풀고 파일 앱에서 ‘둘러보기’를 연다. ‘위치’ 아래에 저장장치 이름이 나타나는지 본다. 보이지 않으면 케이블을 뺐다가 잠금이 풀린 상태에서 다시 연결한다.

2. 저장장치가 지원 포맷인지 확인한다

Apple은 iPhone 외장 저장장치에 APFS, 암호화된 APFS, Mac OS 확장, exFAT, FAT32, FAT 형식을 지원한다고 안내한다. Windows와 Mac, iPhone을 함께 쓸 SSD라면 exFAT이 편한 경우가 많다. 포맷을 바꾸면 데이터가 지워질 수 있으므로 먼저 백업한다.

3. 데이터 파티션이 하나인지 확인한다

Apple 안내에 따르면 iPhone에서 사용할 외장 저장장치는 데이터 파티션이 하나여야 한다. PC에서 여러 파티션으로 나눈 SSD라면 파일 앱에 정상적으로 보이지 않을 수 있으므로 디스크 관리 도구에서 파티션 구성을 확인한다.

4. 전원이 부족한지 확인한다

외장 SSD나 하드디스크가 연결됐다가 사라지거나 아예 나타나지 않으면 전원 부족을 의심할 수 있다. Apple은 자체 전원이 없는 저장장치가 더 많은 전력을 요구할 때 전원 공급형 USB 허브를 사용할 수 있다고 안내한다.

5. 케이블이 데이터 전송을 지원하는지 확인한다

USB-C 모양이 같아도 케이블이 지원하는 기능과 속도는 다를 수 있다. 충전 전용 케이블이거나 손상된 케이블이면 SSD가 인식되지 않을 수 있으므로, 데이터 전송을 지원한다고 명시된 케이블로 직접 연결해 본다.

6. 허브를 쓰고 있다면 SSD만 직접 연결해 본다

허브나 멀티포트를 제거하고 SSD를 아이폰에 직접 연결해 본다. 직접 연결에서는 보이는데 허브를 거치면 안 된다면 허브의 전원 공급, 데이터 규격, 케이블 연결을 따로 확인한다.

7. 새 제품을 사기 전에 고장 범위를 좁힌다

다른 케이블과 다른 저장장치를 하나씩 바꿔 보면서 아이폰 포트, 케이블, 허브, SSD 중 어느 쪽에서 문제가 생기는지 확인한다. 전원 부족이 확인되지 않았는데 바로 고가의 허브를 사기보다 교차 확인을 먼저 하는 편이 비용을 줄일 수 있다.
