윈도우 11 부팅이 느릴 때 가장 먼저 확인할 5가지

윈도우 11 부팅이 느려졌을 때 시작 앱, 저장 공간, 업데이트, 저장장치와 충돌 프로그램을 순서대로 확인하는 방법.

1. 시작 앱부터 줄인다

로그인과 동시에 실행되는 프로그램이 많으면 바탕화면이 보여도 한동안 시스템이 무겁게 느껴질 수 있다. 작업 관리자의 시작 앱에서 매번 자동 실행할 필요가 없는 프로그램을 끈다. 보안 프로그램이나 장치 드라이버 관련 항목처럼 역할을 모르는 항목은 함부로 끄지 않는다.

2. 시스템 드라이브 여유 공간을 확인한다

Windows 업데이트와 임시 파일 처리에는 여유 공간이 필요하다. 시스템 드라이브가 거의 가득 찼다면 다운로드 폴더, 휴지통, 오래된 설치 파일, 사용하지 않는 앱처럼 다시 받을 수 있는 항목부터 정리한다. Microsoft도 저장 공간 확보를 PC 성능 개선 항목으로 안내한다.

3. 업데이트 직후라면 한 번 더 재부팅한다

큰 Windows 업데이트 직후에는 설치 마무리, 검색 인덱싱, 앱 업데이트가 백그라운드에서 이어질 수 있다. 업데이트가 모두 끝났는지 확인하고 재부팅한 뒤에도 계속 느린지 비교한다. 일시적인 업데이트 작업이라면 시간이 지나면서 정상으로 돌아올 수 있다.

4. 저장장치 이상 신호를 확인한다

부팅뿐 아니라 파일 열기나 프로그램 실행도 갑자기 같이 느려졌다면 SSD나 저장장치 상태를 확인한다. 오류 메시지, 비정상적인 멈춤, 파일 복사 속도 저하가 함께 나타나면 중요한 자료를 먼저 백업하고 제조사 진단 도구나 Windows의 드라이브 검사 기능을 사용한다.

5. 특정 프로그램 설치 뒤부터 느려졌는지 본다

최근 설치한 보안 프로그램, RGB 제어 프로그램, 장치 유틸리티처럼 부팅 때 서비스가 같이 실행되는 소프트웨어가 원인일 수 있다. 설치 시점과 느려지기 시작한 시점이 비슷하면 해당 프로그램의 자동 시작을 끄거나 업데이트 여부를 확인한다.

6. 원인이 안 보이면 클린 부팅으로 범위를 좁힌다

Microsoft가 안내하는 클린 부팅은 필수 서비스만 남기고 시작해 충돌 프로그램을 찾는 방법이다. 일반적인 최적화 수단으로 상시 사용하는 방식은 아니며, 문제를 재현하고 원인을 좁히는 용도로만 사용한다.

7. 초기화는 마지막 단계로 둔다

시작 앱과 저장 공간, 업데이트, 저장장치, 프로그램 충돌을 확인한 뒤에도 문제가 계속될 때 시스템 파일 검사나 복구 옵션을 검토한다. 초기화와 포맷은 백업과 프로그램 재설치가 필요하므로 원인 확인 없이 먼저 진행하지 않는다.
