와이파이는 연결됐는데 인터넷이 안 될 때 점검 순서

와이파이는 연결됐는데 인터넷만 안 될 때 기기·공유기·회선 문제를 순서대로 나눠 확인해요.

와이파이 아이콘은 정상인데 웹페이지와 앱만 안 열리면 무작정 네트워크를 초기화하기보다 문제가 한 기기에만 있는지부터 보는 게 빨라요. 여러 기기가 동시에 안 되는지, 공유기까지는 연결되는지, VPN이나 저장된 네트워크 설정이 끼어 있는지를 차례로 확인하면 원인을 크게 줄일 수 있어요.

30초 요약
  • 다른 기기도 같은 와이파이에서 인터넷이 안 되는지 먼저 비교해요.
  • 여러 기기가 동시에 안 되면 공유기·모뎀·통신 회선 쪽을 먼저 확인해요.
  • 한 기기만 문제라면 저장된 네트워크, VPN·프록시, 네트워크 설정을 순서대로 봐요.
  • 공유기 재시작 뒤에도 모든 기기에서 안 되면 통신사 장애나 회선 점검을 확인해요.

먼저 다른 기기도 같은 증상인지 비교해요

원인을 가장 빨리 나누는 방법은 같은 와이파이에 다른 기기를 연결해 보는 거예요. 휴대폰과 노트북이 모두 와이파이에는 붙지만 인터넷이 안 되면 한 기기의 설정 문제일 가능성은 낮아지고, 공유기나 모뎀, 통신 회선 쪽을 먼저 볼 수 있어요. 반대로 다른 기기는 정상인데 특정 PC나 휴대폰만 안 된다면 그 기기의 저장된 네트워크 정보, VPN, 프록시, 네트워크 어댑터 쪽으로 범위를 좁혀요. Microsoft와 Apple도 먼저 다른 기기나 다른 네트워크에서 증상을 비교해 연결 문제의 범위를 가르도록 안내해요. 이 한 번의 비교만 해도 초기화가 필요한지, 공유기 쪽을 봐야 하는지 판단이 훨씬 쉬워져요.

특정 앱이나 사이트만 안 되는지도 구분해요

브라우저에서 사이트 하나만 안 열리는지, 여러 사이트와 다른 앱까지 전부 통신이 안 되는지 확인해요. 특정 사이트만 실패하면 그 서비스 자체의 장애나 DNS 문제일 수 있고, 한 앱만 안 되면 앱 설정이나 보안 프로그램을 따로 봐야 해요. 반대로 브라우저와 메신저, 앱스토어처럼 서로 다른 서비스가 모두 안 되는데 와이파이 표시는 연결 상태라면 기기가 공유기에는 붙었지만 인터넷 경로를 제대로 못 쓰는 상황일 수 있어요. 가능하면 모바일 데이터나 다른 와이파이에서도 같은 사이트를 열어 비교해요. 이렇게 증상을 좁혀 두면 공유기 설정을 건드리거나 네트워크를 초기화하기 전에 문제 범위를 더 정확히 잡을 수 있어요.

여러 기기가 안 되면 공유기와 모뎀부터 다시 확인해요

같은 와이파이를 쓰는 여러 기기에서 동시에 인터넷이 안 되면 공유기와 모뎀의 상태 표시등, 케이블 연결, 통신사 장애 여부를 먼저 봐요. 장비가 멈춘 것 같다면 전원을 껐다 켜는 기본 재시작부터 해요.

  1. 공유기와 모뎀의 전원을 끄고 전원 케이블을 분리해요.
  2. 잠시 뒤 모뎀을 먼저 켜고 회선 표시가 평소 상태로 돌아오는지 확인해요.
  3. 그다음 공유기를 켜고 와이파이에 다시 연결해 인터넷이 되는지 봐요.
  4. 장비 표시등이 계속 비정상이라면 공유기 설정보다 통신사 회선 상태를 먼저 확인해요.

Apple도 Wi-Fi 연결 문제에서 라우터와 케이블 모뎀 재시작을 기본 점검으로 안내해요. 통신사 장비를 임의로 초기화하기 전에 단순 재시작과 장애 공지 확인을 먼저 하는 편이 좋아요.

한 기기만 문제라면 저장된 와이파이를 다시 연결해요

다른 기기는 정상인데 한 기기만 인터넷이 안 되면 그 기기에서 와이파이를 껐다 켜고, 저장된 네트워크를 지운 뒤 다시 연결해 볼 수 있어요. 오래된 인증 정보나 네트워크 설정이 꼬였을 때 이 단계에서 정상으로 돌아오기도 해요.

  1. 현재 연결된 와이파이 이름과 비밀번호를 먼저 확인해요.
  2. 해당 네트워크를 '삭제' 또는 '이 네트워크 지우기'로 제거해요.
  3. 와이파이를 다시 검색해 같은 네트워크를 선택하고 비밀번호를 입력해요.
  4. 연결 뒤 IP 주소를 받았는지, 브라우저와 다른 앱에서 인터넷이 되는지 다시 봐요.

회사나 학교처럼 인증서나 별도 설정이 필요한 네트워크라면 삭제 전에 관리자가 준 연결 방법을 확인하는 편이 안전해요. 일반 가정용 와이파이와 절차가 다를 수 있어요.

VPN과 프록시가 켜져 있다면 잠시 분리해 봐요

와이파이 자체는 연결돼도 VPN 서버나 수동 프록시 설정이 끊겨 있으면 인터넷이 전부 막힌 것처럼 보일 수 있어요. 최근 VPN 앱을 설치했거나 회사·학교용 접속 프로그램을 사용한 뒤부터 증상이 시작됐다면 VPN을 잠시 끄고 다시 확인해요. Windows에서는 프록시 설정이 수동으로 남아 있지 않은지도 보고, iPhone에서는 VPN 상태가 계속 연결 중으로 남아 있지 않은지 살펴요. 다만 회사 보안 정책 때문에 반드시 VPN을 써야 하는 장비라면 임의로 삭제하지 말고 관리자에게 문의해요. VPN을 끄자마자 인터넷이 정상으로 돌아오면 공유기보다 VPN 서비스나 해당 프로필 쪽을 확인하는 게 맞아요. 여러 설정을 한꺼번에 바꾸지 말고 하나씩 바꿔 결과를 비교해요.

Windows 한 대만 안 되면 진단 결과를 기준으로 좁혀요

Windows PC 한 대에서만 문제가 생겼다면 Microsoft가 안내하는 네트워크 문제 해결 절차를 따라 어댑터와 연결 상태를 확인해요. 먼저 Wi-Fi가 켜져 있고 비행기 모드가 꺼져 있는지, 다른 네트워크에 연결되는지, 같은 네트워크의 다른 기기는 정상인지 확인해요. 그다음 Windows의 네트워크 진단 기능을 실행해 표시되는 결과를 봐요. DNS나 어댑터 문제가 나오면 그 항목부터 처리하고, 결과가 없다고 바로 네트워크 초기화로 넘어가지는 않는 편이 좋아요. 네트워크 초기화는 저장된 어댑터와 일부 연결 설정을 다시 구성할 수 있어 VPN이나 회사 네트워크를 다시 설정해야 할 수도 있어요. 문제 해결 도구와 재연결로도 안 될 때 마지막 단계로 남겨 두는 편이 부담이 적어요.

공유기 재시작 뒤에도 모두 안 되면 회선 쪽을 확인해요

공유기와 모뎀을 다시 켰는데도 여러 기기에서 똑같이 인터넷이 안 되고, 다른 와이파이나 모바일 데이터에서는 각 기기가 정상이라면 통신사 회선이나 장비 문제를 의심할 근거가 커져요. 이때는 휴대폰이나 PC를 공장 초기화할 이유가 거의 없어요. 통신사 장애 공지와 지역 장애 여부를 확인하고, 모뎀의 인터넷 표시등 상태와 문제가 시작된 시간을 기록해 상담할 때 전달해요. Apple도 Wi-Fi에는 연결되지만 인터넷을 사용할 수 없는 상태가 계속되면 인터넷 제공업체에 문의하라고 안내해요. 공유기 관리 화면에 접속할 수 있다면 인터넷/WAN 연결 상태만 확인하고, 통신사에서 받은 장비의 설정값을 임의로 초기화하지는 마세요. 회선 문제가 확인되면 기기 설정을 더 바꾸지 않고 복구를 기다리는 편이 맞아요.

자주 묻는 질문

와이파이 표시가 꽉 차 있는데 인터넷이 안 될 수 있나요?

네. 와이파이 표시 강도는 기기와 공유기 사이의 무선 연결 상태를 주로 보여줘요. 공유기에서 인터넷 회선으로 나가는 연결이 끊겼거나 VPN·DNS 같은 설정에 문제가 있으면 와이파이는 연결된 상태여도 인터넷은 안 될 수 있어요.

한 기기만 인터넷이 안 되면 공유기를 초기화해야 하나요?

보통은 바로 초기화하지 않는 편이 좋아요. 다른 기기가 정상이라면 문제가 있는 기기에서 와이파이를 다시 연결하고 VPN·프록시와 네트워크 진단을 먼저 확인해요. 공유기 초기화는 설정을 모두 다시 해야 할 수 있어 마지막 단계로 남겨 두는 편이 나아요.

공유기 전원을 껐다 켜도 여러 기기에서 계속 안 되면요?

다른 네트워크에서는 각 기기가 정상이고 집 와이파이에서만 모두 안 된다면 통신사 회선이나 모뎀 상태를 확인해요. 장애 공지와 장비 표시등을 확인한 뒤 통신사에 회선 진단을 요청하면 기기별 설정을 반복해서 바꾸는 것보다 원인을 빨리 가를 수 있어요.

네트워크 초기화는 언제 하는 게 좋나요?

재연결, VPN·프록시 확인, 기본 진단으로 해결되지 않고 한 기기에서만 문제가 계속될 때 고려해요. 네트워크 초기화 뒤에는 저장된 연결이나 VPN 설정을 다시 구성해야 할 수 있으니 중요한 설정을 먼저 확인하고 진행하는 편이 좋아요.
