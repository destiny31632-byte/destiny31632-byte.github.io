USB-C 케이블은 충전되는데 모니터 출력이 안 되는 이유

USB-C로 충전은 되는데 화면 출력이 안 될 때 포트의 DP Alt Mode, 케이블, 허브와 모니터 입력을 확인하는 방법.

1. USB-C는 모양이 같아도 지원 기능이 다르다

USB-C는 커넥터 형태를 뜻하므로 모든 포트와 케이블이 영상 출력을 지원하는 것은 아니다. 충전만 되거나 데이터 전송만 되는 조합도 있다. 화면 출력이 목적이라면 기기, 포트, 케이블이 영상 전송 규격을 함께 지원해야 한다.

2. 노트북 포트가 DisplayPort Alt Mode를 지원하는지 본다

USB-C 영상 출력에는 DisplayPort Alt Mode가 널리 쓰인다. 노트북이나 태블릿 제품 사양에서 해당 USB-C 포트가 DisplayPort Alt Mode 또는 Thunderbolt 계열 영상 출력을 지원하는지 확인한다. 같은 기기에서도 포트마다 기능이 다를 수 있다.

3. 케이블이 영상 신호를 지원하는지 확인한다

충전 전력만 표시된 케이블은 영상 전송 여부를 알기 어렵다. 제조사 사양에 DisplayPort 영상 출력, USB-C 모니터 연결 또는 지원 해상도가 명시돼 있는지 확인한다. Microsoft도 PC와 외부 디스플레이, 케이블이 모두 해당 Alternate Mode를 지원해야 한다고 안내한다.

4. 허브나 도크를 빼고 직접 연결해 본다

노트북과 모니터를 직접 연결하면 되는데 허브를 거치면 안 된다면 허브나 도크가 원인일 가능성이 높다. 허브의 HDMI·DisplayPort 출력 지원 여부, 호스트 포트 규격, 필요한 전원 공급 조건을 확인한다. 단순 USB 허브는 DisplayPort Alt Mode를 지원하지 않을 수 있다.

5. 모니터 입력 소스를 확인한다

모니터에 HDMI, DisplayPort, USB-C 입력이 여러 개 있으면 실제 연결한 입력으로 소스가 선택됐는지 본다. 자동 입력 전환이 실패하는 경우 수동으로 입력을 바꾸는 것만으로 해결되기도 한다.

6. 다른 포트와 다른 케이블로 교차 확인한다

가능하면 같은 노트북의 다른 USB-C 포트, 다른 영상 지원 케이블, 다른 모니터를 하나씩 바꿔 본다. 한 번에 여러 부품을 바꾸지 않아야 어떤 요소가 문제인지 확인하기 쉽다.

7. 구매할 때는 USB-C 표기보다 기능을 본다

새 케이블이나 도크를 살 때는 USB-C라는 이름만 보지 말고 영상 출력 지원, 최대 해상도와 주사율, 데이터 속도, 전력 공급 사양을 확인한다. 필요한 기능이 명시되지 않은 제품은 모니터 연결용으로 선택하지 않는 편이 안전하다.
