맥북 배터리를 오래 쓰려면 먼저 확인할 것

맥북 배터리를 오래 쓰려면 배터리 상태, 최적화된 충전, 충전 한도와 발열을 어떤 순서로 확인해야 하는지 정리.

1. 충전 습관보다 먼저 배터리 상태를 확인한다

시스템 설정의 배터리 화면에서 배터리 성능 상태와 서비스 관련 메시지를 확인한다. 이미 배터리가 많이 노화된 상태라면 충전 습관을 바꾸는 것만으로 사용 시간이 크게 회복되지는 않는다.

2. 최적화된 배터리 충전을 켜 둔다

Apple의 최적화된 배터리 충전은 사용 패턴을 학습해 Mac이 장시간 전원에 연결될 것으로 예상되면 완충 상태로 머무는 시간을 줄이도록 설계돼 있다. 특별한 이유가 없다면 이 기능을 켜 두고 macOS가 충전을 관리하게 두는 편이 간단하다.

3. 지원되는 Mac이라면 충전 한도를 활용한다

Apple Silicon Mac에서 최신 macOS를 사용하는 경우 충전 한도를 설정할 수 있다. 항상 전원에 연결해 쓰는 시간이 길다면 80~100% 범위에서 한도를 정해 완충 상태로 오래 머무는 시간을 줄일 수 있다. 필요할 때는 메뉴에서 100%까지 충전할 수 있다.

4. 배터리 퍼센트보다 온도를 더 신경 쓴다

Apple은 배터리의 화학적 노화에 온도 이력과 충전 패턴이 영향을 준다고 설명한다. 뜨거운 차 안, 이불 위처럼 열이 빠져나가기 어려운 환경에서 장시간 충전하거나 고부하 작업을 하는 상황을 피한다.

5. 20%나 80% 숫자에 지나치게 맞출 필요는 없다

매번 특정 퍼센트에서 충전기를 꽂고 빼느라 사용성을 크게 희생할 필요는 없다. macOS의 최적화 기능과 충전 한도를 활용하고, 과도한 열을 피하는 편이 실사용에서는 관리하기 쉽다.

6. 사용 시간이 크게 줄었다면 원인을 따로 확인한다

배터리 최대 용량 저하뿐 아니라 화면 밝기, 고성능 앱, 백그라운드 작업도 사용 시간에 영향을 준다. 배터리가 갑자기 빨리 닳는다면 활동 모니터와 배터리 사용 내역을 함께 보고 특정 앱의 비정상적인 사용량이 있는지 확인한다.

7. 오래 보관할 때는 완충 상태로 방치하지 않는다

맥북을 몇 주 이상 사용하지 않고 보관해야 한다면 매일 쓰는 충전 습관과는 따로 생각하는 편이 좋다. 장기 보관 전에는 배터리를 완전히 방전시키거나 계속 100%로 유지하기보다 적당히 충전된 상태로 전원을 끄고, 지나치게 덥거나 추운 장소를 피한다. 다시 사용할 때 배터리가 지나치게 낮아졌다면 충분히 충전한 뒤 켠다.
